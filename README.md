# CodeAlpha Car Price Prediction

## Objective

The objective of this project is to predict the price of cars using Machine Learning based on various features such as car brand, engine size, horsepower, mileage, fuel type, and other car specifications.

## Dataset

This project uses the Car Price Assignment dataset.

The dataset contains different features related to cars and their prices.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model

Random Forest Regression

## Project Steps

1. Loaded the car price dataset.
2. Performed data exploration.
3. Checked missing and duplicate values.
4. Cleaned the dataset.
5. Performed data visualization.
6. Separated features and target variable.
7. Encoded categorical features.
8. Split the data into training and testing sets.
9. Trained a Random Forest Regression model.
10. Predicted car prices.
11. Evaluated the model using MAE, RMSE, and R2 Score.
12. Visualized actual vs predicted prices.

## Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R2 Score

## Result

The Random Forest Regression model successfully predicted car prices based on the given car features.

## Conclusion

This project demonstrates how Machine Learning can be used for predicting car prices. It helped in understanding data preprocessing, categorical feature encoding, regression modeling, prediction, and model evaluation.
